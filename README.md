# Goldstone Psychiatry & Neuromodulation Center Landing Page

Marketing landing page for Goldstone Psychiatry (Houston, TX), focused on physician-led TMS therapy for treatment-resistant depression.

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
